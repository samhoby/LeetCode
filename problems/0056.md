# 56. Merge Intervals

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Sorting](../README.md#sorting), [Quicksort](../README.md#quicksort)
- **Link:** https://leetcode.com/problems/merge-intervals/

## Key idea
Once the intervals are sorted by start, an interval can only overlap the ones right before it. So go through them in order, keeping the merged ones. If the next interval starts before or where the last merged one ends, they overlap and become one that ends at the later end. If not, it starts a new merged interval.

Example with `[[1,3],[2,6],[8,10],[15,18]]`: [1,3] and [2,6] overlap because 3 >= 2, so they become [1,6]. [8,10] starts after 6, so it starts a new one, and so does [15,18]. The result is `[[1,6],[8,10],[15,18]]`.

The sort uses the built-in sort, not a Quicksort written by hand.

## Pattern
Sort + merge in one pass: after sorting by start, each interval only needs to be compared with the last merged one.

## Complexity
O(n log n) time, O(n) space.
