# 56. Merge Intervals

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Sorting](../README.md#sorting), [Quicksort](../README.md#quicksort)
- **Link:** https://leetcode.com/problems/merge-intervals/

## Key idea
Sort the intervals by start, so an interval that overlaps the previous one always comes right after it. Then go through them once, keeping the merged intervals in `list`. If the current interval starts before or at the end of the last one in `list` (`lastElemOfPrev >= firstElemOfCurr`), they overlap, so the last one's end becomes the bigger of the two ends. Otherwise the current interval is added as a new one.

Example with `[[1,3],[2,6],[8,10],[15,18]]`: `[1,3]` and `[2,6]` overlap because 3 >= 2, so they become `[1,6]`. `[8,10]` starts after 6, so it's added. `[15,18]` too. The result is `[[1,6],[8,10],[15,18]]`.

The sort is done by the built-in `sortWith`, not by a Quicksort written by hand.

## Pattern
Sort + merge in one pass: after sorting by start, each interval only needs to be compared with the last merged one.

## Complexity
O(n log n) time, O(n) space.

## Code
```kotlin
class Solution {
    fun merge(intervals: Array<IntArray>): Array<IntArray> {
        intervals.sortWith { a, b  -> a[0].compareTo(b[0]) }

        val list = mutableListOf<IntArray>(intervals[0])

        for (i in 1..intervals.lastIndex) {
            val lastElemOfPrev = list.last().last()
            val firstElemOfCurr = intervals[i][0]
            val lastElemOfCurr = intervals[i].last()

            if (lastElemOfPrev >= firstElemOfCurr) {
                list.last()[1] = maxOf(lastElemOfPrev, lastElemOfCurr)
            } else {
                list.add(intervals[i])
            }
        }

        return list.toTypedArray()
    }
}
```
