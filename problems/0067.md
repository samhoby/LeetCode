# 67. Add Binary

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math), [String](../README.md#string), [Bit Manipulation](../README.md#bit-manipulation), [Simulation](../README.md#simulation)
- **Link:** https://leetcode.com/problems/add-binary/

## Key idea
Add the two binary strings the way it's done by hand, starting from the last digit of each. At every position, add the two digits (0 if that string has run out) plus the carry. In binary, the digit written is the sum mod 2 and the carry is the sum divided by 2. Keep going while either string still has digits or there's a carry left. The digits come out from right to left, so the result is reversed at the end.

Example with `a = "11"` and `b = "1"`: 1 + 1 = 2 writes 0 and carries 1. Then 1 + the carry = 2 writes 0 and carries 1 again. Then only the carry is left, which writes 1. Read from left to right, the answer is "100".

## Pattern
Simulate the addition from right to left with a carry, like [Plus One](0066.md), but in base 2.

## Complexity
O(n) time, O(n) space, where n is the length of the longer string.
