# 27. Remove Element

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Two Pointers](../README.md#two-pointers)
- **Link:** https://leetcode.com/problems/remove-element/

## Key idea
The array `nums` has to keep every number that isn't `val` at the front. Read the numbers one by one, and each one that isn't `val` is written at the next free spot at the front, in the same order. The answer `k` is how many were written, and what's left after them doesn't matter.

Example with `nums = [3,2,2,3]` and `val = 3`: only the two 2s are kept, so the front becomes `[2,2]` and `k` is 2.

## Pattern
Two pointers in the same direction, one that reads and one that writes, like [Remove Duplicates from Sorted Array](0026.md). Only the rule for keeping a number changes.

## Complexity
O(n) time, O(1) space.
