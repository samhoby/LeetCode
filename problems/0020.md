# 20. Valid Parentheses

- **Difficulty:** Easy
- **Topics:** [String](../README.md#string), [Stack](../README.md#stack), [Bracket Sequences](../README.md#bracket-sequences)
- **Link:** https://leetcode.com/problems/valid-parentheses/

## Key idea
Every closing bracket must match the most recent unclosed opening bracket, which is exactly what a stack gives. When an opening bracket comes, push the closing bracket it expects. When a closing bracket comes, the top of the stack must be that same character; if the stack is empty or it's different, the string is invalid. At the end, the stack must be empty, otherwise some brackets were never closed. An odd length can never be valid, so return `false` early.

## Pattern
Bracket matching with a stack. Pushing the expected closing bracket instead of the opening one makes the check a single comparison (`stack.pop() != char`), with no map needed.

## Complexity
O(n) time, O(n) space.

## Code
```kotlin
class Solution {
    fun isValid(s: String): Boolean {
        if (s.length % 2 != 0) return false

        val stack = Stack<Char>()

        for (char in s) {
            when (char) {
                '(' -> stack.push(')')
                '[' -> stack.push(']')
                '{' -> stack.push('}')
                else -> if (stack.isEmpty() || stack.pop() != char) return false
            }
        }

        return stack.isEmpty()
    }
}
```
