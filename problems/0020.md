# 20. Valid Parentheses

- **Difficulty:** Easy
- **Topics:** [String](../README.md#string), [Stack](../README.md#stack), [Bracket Sequences](../README.md#bracket-sequences)
- **Link:** https://leetcode.com/problems/valid-parentheses/

## Key idea
Every closing bracket must match the most recent opening bracket that's still open, which is exactly what a stack keeps. For each opening bracket, push the closing bracket it expects. For each closing bracket, the top of the stack must be that same bracket, otherwise the string is invalid. At the end the stack must be empty, or some brackets were never closed. A string of odd length can never be valid.

## Pattern
Bracket matching with a stack. Pushing the expected closing bracket instead of the opening one makes the check a single comparison (`stack.pop() != char`), with no map needed.

## Complexity
O(n) time, O(n) space.

## Code
```kotlin
class Solution {
    fun isValid(s: String): Boolean {
        if (s.length % 2 != 0) return false

        val stack = Stack<Char>()

        for (char in s) {
            when (char) {
                '(' -> stack.push(')')
                '[' -> stack.push(']')
                '{' -> stack.push('}')
                else -> if (stack.isEmpty() || stack.pop() != char) return false
            }
        }

        return stack.isEmpty()
    }
}
```
