# 1. Two Sum

- **Difficulty:** Easy
- **Level:** Junior
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table)
- **Link:** https://leetcode.com/problems/two-sum/

## Key idea
For each number, I'm looking for `target - num`. I store the numbers I've already seen in a map, and at each step I check whether the `complement` is already there.

## Pattern
Hash map to turn an O(n) lookup into O(1).

## Code
```kotlin
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {
        val seen = HashMap<Int, Int>()
        
        for (i in nums.indices) { 
            val num = nums[i]
            val complement = target - num
            
            if (complement in seen) {
	            val j = seen[complement]
	            if (j != null) {
		            return intArrayOf(j, i)
	            }
            }
            seen[num] = i
        }
        
        return intArrayOf()
    }
}
```
