# 1. Two Sum

- **Difficulty:** Easy
- **Topics:** [Junior](../README.md#junior), [Array](../README.md#array), [Hash Table](../README.md#hash-table)
- **Link:** https://leetcode.com/problems/two-sum/

## Key idea
For each number, the other number of the pair has to be `target` minus it. Keep the numbers already seen in a hash map with their indices, so checking whether that other number came earlier is a single lookup instead of a second loop.

## Pattern
Hash map to turn an O(n) lookup into O(1).

## Code
```kotlin
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {
        val seen = HashMap<Int, Int>()
        
        for (i in nums.indices) { 
            val num = nums[i]
            val complement = target - num
            
            if (complement in seen) {
	            val j = seen[complement]
	            if (j != null) {
		            return intArrayOf(j, i)
	            }
            }
            seen[num] = i
        }
        
        return intArrayOf()
    }
}
```
