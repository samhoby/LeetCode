# 136. Single Number

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Bit Manipulation](../README.md#bit-manipulation)
- **Link:** https://leetcode.com/problems/single-number/

## Key idea
XOR every number together. A number XORed with itself is 0, and XOR doesn't care about order, so each pair cancels out and only the single number is left. It works because (N xor Q) xor Q = N. A reduce with XOR over `nums` does the same in one line.

## Pattern
Bit manipulation with XOR: `x xor x = 0` and `x xor 0 = x`, and the order doesn't matter, so the pairs don't need to be next to each other. `singleOne` starts at `0` because `0` doesn't change the result.

## Complexity
O(n) time, O(1) space.
