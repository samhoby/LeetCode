# 136. Single Number

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Bit Manipulation](../README.md#bit-manipulation)
- **Link:** https://leetcode.com/problems/single-number/

## Key idea
XOR every number into `singleOne`. Every number that appears twice cancels itself out, so only the single one is left at the end. It works because (N xor Q) xor Q = N.
Also, `nums.reduce { a, b -> a xor b }` does the same in one line, but it's slower.

## Pattern
Bit manipulation with XOR: `x xor x = 0` and `x xor 0 = x`, and the order doesn't matter, so the pairs don't need to be next to each other. `singleOne` starts at `0` because `0` doesn't change the result.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun singleNumber(nums: IntArray): Int {
        var singleOne = 0

        for (num in nums) {
            singleOne = singleOne xor num
        }

        return singleOne
    }
}
```
