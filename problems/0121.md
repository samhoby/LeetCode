# 121. Best Time to Buy and Sell Stock

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Dynamic Programming](../README.md#dynamic-programming)
- **Link:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock/

## Key idea
The best sale on any day is buying at the cheapest price before it. So go through the days in order, keeping the lowest price seen so far. Each day, selling earns that day's price minus the lowest price, and the answer is the best of those. Since the lowest price only comes from earlier days, the buy always happens before the sell.

## Pattern
Single pass with two state variables: a running minimum and a running best result. `maxProfit` is replaced, not summed, so it counts one buy and one sell.

## Complexity
O(n) time, O(1) space.
