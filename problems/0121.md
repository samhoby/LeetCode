# 121. Best Time to Buy and Sell Stock

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Dynamic Programming](../README.md#dynamic-programming)
- **Link:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock/

## Key idea
Scan the prices from left to right, keeping the lowest price seen so far (`minBuy`). Each day, compute the profit of selling today (`price - minBuy`) and keep the best one (`maxProfit`). Because `minBuy` only knows past days, the buy always comes before the sell.

## Pattern
Single pass with two state variables: a running minimum and a running best result. `maxProfit` is replaced, not summed, so it counts one buy and one sell.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun maxProfit(prices: IntArray): Int {
        var minBuy = prices[0]
        var maxProfit = 0

        for (i in prices.indices) {
            val price = prices[i]
            val profitOfDay = price - minBuy
            
            if (price < minBuy) {
                minBuy = price
            }   

            if (profitOfDay > maxProfit) {
                maxProfit = profitOfDay
            }
        }

        return maxProfit
    }
}
```
