# 344. Reverse String

- **Difficulty:** Easy
- **Topics:** [Two Pointers](../README.md#two-pointers), [String](../README.md#string)
- **Link:** https://leetcode.com/problems/reverse-string/

## Key idea
Swap the first and last characters, then the second and second to last, and so on until the middle. `left` starts at the beginning and `right` at the end. Each step swaps them and moves both toward the middle. When they meet, every character has been swapped once.

`s[left++]` uses `left` first and then increments it, so the swap and the move happen on the same line.

Example with `['h', 'e', 'l', 'l', 'o']`: swap h and o, then e and l, the middle l stays, giving `['o', 'l', 'l', 'e', 'h']`.

## Pattern
Two pointers moving inward from both ends, swapping in place.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun reverseString(s: CharArray): Unit {
        var left = 0
        var right = s.lastIndex

        while (left < right) {
            val tmp = s[left]
            s[left++] = s[right]
            s[right--] = tmp
        }
    }
}
```
