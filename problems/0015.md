# 15. 3Sum

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Two Pointers](../README.md#two-pointers), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/3sum/description/

## Key idea
After sorting, fix the first number of the triplet and look for a pair after it that sums to its negative. Since the rest is sorted, two pointers find that pair: one at each end, moving the left one when the sum is too small and the right one when it's too big. Skipping equal values, both for the fixed number and after each triplet found, keeps duplicates out. Once the fixed number is positive, no triplet can sum to 0.

## Pattern
Sort + fixed element + two pointers. Skipping equal neighbors replaces the `Set` for deduplication.

## Code
```kotlin
class Solution {
    fun threeSum(nums: IntArray): List<List<Int>> {
        val sums = ArrayList<List<Int>>()
        val lastIndex = nums.lastIndex
        nums.sort()
        
        for (i in 0 until lastIndex-1) {
            // 1. if the first number is already positive, so result is never 0
            if (nums[i] > 0) break 
            // 2. if the first number is equal to the previous elem, skip
            if (i > 0 && nums[i] == nums[i-1]) continue
            
            // 3. two pointers 
            var left = i+1
            var right = lastIndex
            
            while (left < right) {
                val sum = nums[i] + nums[left] + nums[right]
                when {
                    sum < 0 -> left++
                    sum > 0 -> right--
                    else -> {
                        // 4. add, adjust pointers and skip the equals (like 2) 
                        sums.add(listOf(nums[i], nums[left], nums[right]))
                        left++
                        right--
                        while(left < right && nums[left] == nums[left-1]) left++
                        while(left < right && nums[right] == nums[right+1]) right--
                    }
                }
            }
        }
        return sums
    }
}
```
