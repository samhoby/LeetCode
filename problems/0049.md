# 49. Group Anagrams

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [String](../README.md#string), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/group-anagrams/

## Key idea
Anagrams have the same sorted letters (eat, tea and ate all become "aet"), so the sorted string is the key of each group. To sort, count the letters in `count`, then build `key` by taking the smallest letter left each time and decrementing it. After that, `count` is all 0 again, so it's reused for the next string.

## Pattern
Group with a hash map by a key that's the same for all anagrams: the sorted letters. With only 26 letters, a counting sort builds that key in O(k) instead of O(k log k). The `LinkedHashMap` keeps the groups in input order, and `initialCapacity` gives it enough room to never resize.

## Complexity
O(n · k) time, O(n · k) space, where n is the number of strings and k is the longest length.

## Code
```kotlin
class Solution {
    fun groupAnagrams(strs: Array<String>): List<List<String>> {
        // resizes past 75% full (load factor 0.75)
        val initialCapacity = (strs.size / 0.75f).toInt() + 1
        val groups = LinkedHashMap<String, MutableList<String>>(initialCapacity)
        val count = IntArray(26)             

        for (str in strs) {
            for (c in str) count[c - 'a']++

            var l = 0
            val key = CharArray(str.length) {
                while (count[l] == 0) l++
                count[l]--
                'a' + l
            }

            groups.getOrPut(String(key)) { ArrayList() }.add(str)
        }
        return ArrayList(groups.values)
    }
}
```
