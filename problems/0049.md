# 49. Group Anagrams

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [String](../README.md#string), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/group-anagrams/

## Key idea
Anagrams have the same count of each letter. So for each string, count its letters in `count` and turn that into a `key` with `joinToString(",")`. Strings with the same `key` go in the same group. The commas matter: without them, counts like 1, 11 and 11, 1 would both become "111".

Code 1: `groupBy` puts each string in a map under its `key`, and `.values.toList()` returns just the groups.

Code 2: what `groupBy` does in the background, written by hand. `groups` is a `LinkedHashMap` from each `key` to its group. `getOrPut` returns the group for that `key`, creating an empty one first if it doesn't exist yet, and the string is added to it. A `LinkedHashMap` keeps the groups in the order they first appeared.

Example with `["eat", "tea", "tan", "ate", "nat", "bat"]`: eat, tea and ate all have one a, one e and one t, so they share a key. The result is `[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]`.

Neither code sorts. The Sorting topic is for the other approach: use the sorted letters of each string as the key. It's simpler, but sorting each string costs O(k log k) instead of O(k).

## Pattern
Group with a hash map by a key that's the same for all anagrams (the letter counts).

## Complexity
O(n · k) time, O(n · k) space, where n is the number of strings and k is the longest length.

## Code 1
```kotlin
class Solution {
    fun groupAnagrams(strs: Array<String>): List<List<String>> =
        strs.groupBy { str ->
            val count = IntArray(26)
            for (c in str) count[c - 'a']++
            count.joinToString(",")
        }.values.toList()
}
```

## Code 2
```kotlin
class Solution {
    fun groupAnagrams(strs: Array<String>): List<List<String>> {
        val groups = LinkedHashMap<String, MutableList<String>>()

        for (str in strs) {
            val count = IntArray(26)
            for (c in str) count[c - 'a']++
            val key = count.joinToString(",")

            // get the group of this key (or create it) and add the string
            groups.getOrPut(key) { mutableListOf() }.add(str)
        }

        return groups.values.toList()
    }
}
```
