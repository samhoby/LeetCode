# 49. Group Anagrams

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [String](../README.md#string), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/group-anagrams/

## Key idea
Anagrams have exactly the same letters, the same number of times. So for each string, count how many of each of the 26 letters it has, and use those 26 counts as the key: eat, tea and ate all have one a, one e and one t, so they get the same key. A hash map groups the strings by that key.

This solution doesn't sort. The Sorting topic is for the other approach: use each string's sorted letters as the key, which costs O(k log k) per string instead of O(k).

## Pattern
Group with a hash map by a key that's the same for all anagrams: the letter counts. Empty strings all get the key with 26 zeros, so they end up in the same group.

## Complexity
O(n · k) time, O(n · k) space, where n is the number of strings and k is the longest length.
