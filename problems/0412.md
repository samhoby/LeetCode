# 412. FizzBuzz

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math), [String](../README.md#string), [Simulation](../README.md#simulation)
- **Link:** https://leetcode.com/problems/fizz-buzz/

## Key idea
For each number from 1 to `n`, the first condition that matches decides the output, so check the most specific case first: divisible by 15 (both 3 and 5), then by 3, then by 5, otherwise the number itself.

## Pattern
Simulation with ordered conditions: the first matching branch wins, so put the most specific case first. 

## Complexity
O(n) time, O(n) space for the output.
