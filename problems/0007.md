# 7. Reverse Integer

- **Difficulty:** Medium
- **Topics:** [Math](../README.md#math)
- **Link:** https://leetcode.com/problems/reverse-integer/

## Key idea
Reverse the digits by repeatedly taking the last digit off `x` (mod 10) and appending it to the result (times 10, plus the digit), until `x` is 0. The remainder keeps the sign of `x`, so negative numbers reverse the same way. The reversed number can be too big for 32 bits even when `x` fits, so it's built with 64 bits and the answer is 0 if it doesn't fit back into 32.

Example with `x = -123`: the digits come off as -3, -2 and -1, building -3, -32 and -321. With `x = 1534236469`, the reverse is 9646324351, which doesn't fit in 32 bits, so the answer is 0.

The problem says to assume 64-bit integers aren't allowed. LeetCode still accepts this solution, but the strict way is to check before each step that the result times 10, plus the digit, still fits in 32 bits.

## Pattern
Digit manipulation with mod 10 and divide by 10, like [Palindrome Number](0009.md).

## Complexity
O(log x) time, O(1) space.

## Code
```kotlin
class Solution {
    fun reverse(x: Int): Int {
        var value = x
        var res = 0L

        while (value != 0) {
            res = res * 10 + value % 10
            value /= 10
        }

        return if (res in Int.MIN_VALUE..Int.MAX_VALUE) res.toInt() else 0
    }
}
```
