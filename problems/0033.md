# 33. Search in Rotated Sorted Array

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/search-in-rotated-sorted-array/

## Key idea
In a rotated sorted array, at least one half around the middle is always sorted. Find which one by comparing its ends, then check if `target` falls inside that sorted half's range. If it does, search there, otherwise search the other half. Each step cuts the search space in half.

Example with `[4, 5, 6, 7, 0, 1, 2]` and `target = 0`: the middle is 7, the left half 4..7 is sorted but doesn't have 0, so search the right half. There the middle is 1, the left part 0..1 is sorted and has 0, so search it, and 0 is found at index 4.

## Pattern
Binary search where you first find the sorted side, then check if `target` is in it. Same rotated array idea as [Find Minimum in Rotated Sorted Array](0153.md).

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun search(nums: IntArray, target: Int): Int {
        var left = 0
        var right = nums.lastIndex

        while (left <= right) {
            val mid = (left + right) / 2
            val value = nums[mid]

            if (value == target) return mid

            when {
                nums[left] <= value -> {
                    if (target in nums[left] until value) {
                        right = mid - 1
                    } else {
                        left = mid + 1
                    }
                }
                else -> {
                    if (target in (value+1)..nums[right]) {
                        left = mid + 1
                    } else {
                        right = mid - 1
                    }
                }
            }
        }

        return -1
    }
}
```
