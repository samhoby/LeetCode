# 33. Search in Rotated Sorted Array

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/search-in-rotated-sorted-array/

## Key idea
In a rotated sorted array, at least one side of `mid` is always sorted. If `nums[left] <= value`, the left side is sorted, so check if `target` is in it (`nums[left] until value`): if yes go left, if not go right. Otherwise the right side is sorted, so check `(value + 1)..nums[right]` the same way. `value` itself is left out of both ranges because it was already checked.

Example with `[4, 5, 6, 7, 0, 1, 2]` and `target = 0`: `value` is 7, the left side 4..7 is sorted but doesn't have 0, so go right. Then `value` is 1, the left side 0..1 is sorted and has 0, so go left. Then `value` is 0, found at index 4.

## Pattern
Binary search where you first find the sorted side, then check if `target` is in it. Same rotated array idea as [Find Minimum in Rotated Sorted Array](0153.md).

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun search(nums: IntArray, target: Int): Int {
        var left = 0
        var right = nums.lastIndex

        while (left <= right) {
            val mid = (left + right) / 2
            val value = nums[mid]

            if (value == target) return mid

            when {
                nums[left] <= value -> {
                    if (target in nums[left] until value) {
                        right = mid - 1
                    } else {
                        left = mid + 1
                    }
                }
                else -> {
                    if (target in (value+1)..nums[right]) {
                        left = mid + 1
                    } else {
                        right = mid - 1
                    }
                }
            }
        }

        return -1
    }
}
```
