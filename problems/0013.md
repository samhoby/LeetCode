# 13. Roman to Integer

- **Difficulty:** Easy
- **Topics:** [Hash Table](../README.md#hash-table), [Math](../README.md#math), [String](../README.md#string)
- **Link:** https://leetcode.com/problems/roman-to-integer/

## Key idea
Each symbol has a fixed value. Values are normally added, but a smaller symbol right before a bigger one is subtracted (IV = 5 - 1). Reading from right to left makes this simple: if a symbol is smaller than the one to its right, subtract it, otherwise add it.

## Pattern
Hash map as a lookup table + backward scan with one state variable. 

## Complexity
O(n) time, O(1) space.

## Code 1
```kotlin
class Solution {
    private val romanToInt = mapOf(
        'I' to 1,
        'V' to 5,
        'X' to 10,
        'L' to 50,
        'C' to 100,
        'D' to 500,
        'M' to 1000
    )
    
    fun romanToInt(s: String): Int {
        var res = 0
        var prev = 0  
        
        for (i in s.lastIndex downTo 0) {
            val curr = romanToInt[s[i]]!!
            
            if (curr < prev) res -= curr else res += curr
            
            prev = curr
        }
        
        return res
    }
}
```
