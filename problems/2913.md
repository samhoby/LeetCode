# 2913. Subarrays Distinct Element Sum of Squares I

- **Difficulty:** Easy
- **Topics:** [Mid Level](../README.md#mid-level), [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Binary Indexed Tree](../README.md#binary-indexed-tree), [Segment Tree](../README.md#segment-tree)
- **Link:** https://leetcode.com/problems/subarrays-distinct-element-sum-of-squares-i/

## Key idea
Go through every subarray: `i` is the start and `j` extends the end one step at a time. `seen` holds the distinct values of `nums[i..j]`, so `seen.size` is the distinct count of the current subarray and `seen.size * seen.size` is added to `res`. When `j` moves, only `nums[j]` is added, so the set is reused instead of rebuilt for every subarray. For each new `i`, `seen` starts empty.

Example with `[1, 2, 1]`: the subarrays `[1]`, `[2]`, `[1]` have 1 distinct value each, `[1, 2]` and `[2, 1]` have 2, `[1, 2, 1]` has 2, so the answer is 1 + 1 + 1 + 4 + 4 + 4 = 15.

It's possible to do better with a Segment Tree (or a Binary Indexed Tree), which is what those topics are for. But `nums.size` is at most 100 here (and `nums[i]` is in `1..100`), so there are only about 5000 subarrays and the simple loops are enough. The Segment Tree is needed for the harder version, Subarrays Distinct Element Sum of Squares II, where `nums.size` goes up to 10⁵.

## Pattern
Brute force over all subarrays, extending the end and keeping a running `HashSet` of distinct values.

## Complexity
O(n²) time, O(n) space.

## Code
```kotlin
class Solution {
    fun sumCounts(nums: List<Int>): Int {
        var res = 0

        for (i in nums.indices) {
            val seen = HashSet<Int>()
            for (j in i until nums.size) {
                seen.add(nums[j])
                res += seen.size * seen.size
            }
        }

        return res
    }
}
```
