# 2913. Subarrays Distinct Element Sum of Squares I

- **Difficulty:** Easy
- **Topics:** [Mid Level](../README.md#mid-level), [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Binary Indexed Tree](../README.md#binary-indexed-tree), [Segment Tree](../README.md#segment-tree)
- **Link:** https://leetcode.com/problems/subarrays-distinct-element-sum-of-squares-i/

## Key idea
Check every subarray. For each start, extend the end one element at a time and keep the distinct values seen so far in a hash set. Its size is the distinct count of the current subarray, so add its square. Extending the end only adds one value, so the set is reused instead of rebuilt, and it starts empty again for each new start.

Example with `[1, 2, 1]`: the subarrays `[1]`, `[2]`, `[1]` have 1 distinct value each, `[1, 2]` and `[2, 1]` have 2, `[1, 2, 1]` has 2, so the answer is 1 + 1 + 1 + 4 + 4 + 4 = 15.

It's possible to do better with a Segment Tree (or a Binary Indexed Tree), which is what those topics are for. But `nums` has at most 100 elements here (and each value is in `1..100`), so there are only about 5000 subarrays and the simple loops are enough. The Segment Tree is needed for the harder version, Subarrays Distinct Element Sum of Squares II, where `nums` can have up to 10⁵ elements.

## Pattern
Brute force over all subarrays, extending the end and keeping a running `HashSet` of distinct values.

## Complexity
O(n²) time, O(n) space.
