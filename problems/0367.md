# 367. Valid Perfect Square

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/valid-perfect-square/description/

## Key idea
Binary search on the answer: look for a number between 1 and `num` whose square is exactly `num`. If the square is too small, search higher, if it's too big, search lower. The square can overflow a 32-bit integer, so it's computed with 64 bits.

## Pattern
Binary search on the answer, searching the range of possible results instead of an array. 

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun isPerfectSquare(num: Int): Boolean {
        val numLong = num.toLong()
        var left = 1L
        var right = numLong
        
        while (left <= right) {
            val mid = (left + right) / 2
            val square = mid * mid
            
            when {
                square == numLong -> return true
                square < numLong -> left = mid + 1
                else -> right = mid - 1
            }            
        }
        
        return false
    }
}
```
