# 367. Valid Perfect Square

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/valid-perfect-square/description/

## Key idea
Binary search on the answer: look for a number between 1 and `num` whose square is exactly `num`. If the square is too small, search higher, if it's too big, search lower. The square can be too big for 32 bits, so with fixed-size integers it has to be computed with 64 bits.

## Pattern
Binary search on the answer, searching the range of possible results instead of an array. 

## Complexity
O(log n) time, O(1) space.
