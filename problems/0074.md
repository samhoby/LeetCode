# 74. Search a 2D Matrix

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Binary Search](../README.md#binary-search), [Matrix](../README.md#matrix)
- **Link:** https://leetcode.com/problems/search-a-2d-matrix/

## Key idea
Each row is sorted and starts after the previous row ends, so reading `matrix` row by row gives one sorted list of m · n numbers. Binary search that list without building it: position p of the list is row p / n, column p mod n of `matrix`.

Example with `[[1,3,5,7],[10,11,16,20],[23,30,34,60]]` and `target = 3`: the list has positions 0 to 11. Position 5 is row 1, column 1, which is 11, too big, so search 0 to 4. Position 2 is row 0, column 2, which is 5, still too big, so search 0 to 1. Position 0 is 1, too small, so search 1 to 1. Position 1 is 3, found.

## Pattern
Binary search on a matrix treated as one flat sorted array, turning each position into a row and column.

## Complexity
O(log(m · n)) time, O(1) space, where m is the number of rows and n the number of columns.
