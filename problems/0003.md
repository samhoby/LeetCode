# 3. Longest Substring Without Repeating Characters

- **Difficulty:** Medium
- **Topics:** [Staff](../README.md#staff), [Hash Table](../README.md#hash-table), [String](../README.md#string), [Sliding Window](../README.md#sliding-window)
- **Link:** https://leetcode.com/problems/longest-substring-without-repeating-characters/

## Key idea
Keep a window `s[i..j]` with no repeated characters. `j` moves forward one character at a time. If `s[j]` is already in the window (`seen[idx] > 0`), move `i` forward and remove characters from `seen` until it's gone. Then add `s[j]` and check if the window is the biggest so far (`maxLen`).

Example with `"abcabcbb"`: the window grows to `"abc"` (3). At the second `a`, `i` moves past the first `a`, so the window becomes `"bca"`, still 3. The answer is 3.

`seen` is an array indexed by the character code, so it works as a small hash table. 128 slots are enough because the input is ASCII.

## Pattern
Sliding window of variable size: grow with `j`, shrink with `i` until the window is valid again.

## Complexity
O(n) time. O(1) space.

## Code
```kotlin
class Solution {
    fun lengthOfLongestSubstring(s: String): Int {
        var maxLen = 0
        val seen = IntArray(128)
        var i = 0

        for (j in s.indices) {
            val idx = s[j].code
            while (seen[idx] > 0) {
                seen[s[i].code]--
                i++
            }

            seen[idx]++
            maxLen = maxOf(maxLen, j - i + 1)
        }

        return maxLen
    }
}
```
