# 3. Longest Substring Without Repeating Characters

- **Difficulty:** Medium
- **Topics:** [Staff](../README.md#staff), [Hash Table](../README.md#hash-table), [String](../README.md#string), [Sliding Window](../README.md#sliding-window)
- **Link:** https://leetcode.com/problems/longest-substring-without-repeating-characters/

## Key idea
Keep a window of characters with no repeats and slide it over `s`. Each new character extends the window on the right. If it's already in the window, shrink the window from the left until that earlier copy is gone. The answer is the biggest size the window ever reaches.

Example with `"abcabcbb"`: the window grows to "abc" (3). At the second a, the first a leaves, so the window becomes "bca", still 3. The answer is 3.

Since the characters are ASCII, an array with one slot per character code works as the hash table that tracks what's in the window.

## Pattern
Sliding window of variable size: grow with `j`, shrink with `i` until the window is valid again.

## Complexity
O(n) time. O(1) space.

## Code
```kotlin
class Solution {
    fun lengthOfLongestSubstring(s: String): Int {
        var maxLen = 0
        val seen = IntArray(128)
        var i = 0

        for (j in s.indices) {
            val idx = s[j].code
            while (seen[idx] > 0) {
                seen[s[i].code]--
                i++
            }

            seen[idx]++
            maxLen = maxOf(maxLen, j - i + 1)
        }

        return maxLen
    }
}
```
