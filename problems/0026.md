# 26. Remove Duplicates from Sorted Array

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Two Pointers](../README.md#two-pointers)
- **Link:** https://leetcode.com/problems/remove-duplicates-from-sorted-array/

## Key idea
The array `nums` is sorted, so equal numbers are always next to each other, and a number is new when it's different from the one right before it. Keep the unique numbers at the front, in order: read the numbers one by one, and every new one is written at the next free spot at the front. The first number is always new. The answer `k` is how many were written, and what's left after them doesn't matter.

Example with `[0,0,1,1,1,2,2,3,3,4]`: the new numbers are 0, 1, 2, 3 and 4, so the front becomes `[0,1,2,3,4]` and `k` is 5.

## Pattern
Two pointers in the same direction, one that reads and one that writes, like [Move Zeroes](0283.md). Comparing with the previous number is enough because the array is sorted.

## Complexity
O(n) time, O(1) space.
