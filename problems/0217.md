# 217. Contains Duplicate

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/contains-duplicate/

## Key idea
There's a duplicate if some number was already seen earlier. Keep the numbers seen so far in a hash set, which answers "have I seen this?" in O(1). The first number already in the set is a duplicate. If there's none, all numbers are distinct.

## Pattern
“Have I seen this before?” → hash set, O(1) lookup. 
Alternative: sort first and compare neighbors, which is O(n log n) but needs no extra space.

|         | Hashset | Neighbors  |
| ------- | ------- | ---------- |
| Time    | O(n)    | O(n log n) |
| Space   | O(n)    | O(1)       |
| Sorting | No      | Yes        |

## Code
```kotlin
class Solution {
    fun containsDuplicate(nums: IntArray): Boolean {
        val seen = HashSet<Int>()
        for (num in nums) {
            if (!seen.add(num)) return true
        }
        
        return false
    }
}
```
