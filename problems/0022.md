# 22. Generate Parentheses

- **Difficulty:** Medium
- **Topics:** [String](../README.md#string), [Dynamic Programming](../README.md#dynamic-programming), [Backtracking](../README.md#backtracking), [Bracket Sequences](../README.md#bracket-sequences)
- **Link:** https://leetcode.com/problems/generate-parentheses/

## Key idea
Build the strings one bracket at a time, and only add a bracket that keeps the string on its way to being valid. An opening bracket can be added while fewer than n have been used. A closing bracket can be added only while more brackets are open than closed, so it always has one to close. A string that reaches 2n brackets this way is valid, so it goes into the answer. After trying a choice, undo it and try the other one, so every valid string is reached exactly once.

Example with n = 2: starting with "((" only allows "(())". Starting with "()" allows another "(" and then ")", giving "()()". The answer is `["(())", "()()"]`.

This solution doesn't use dynamic programming. That topic is for another approach: every valid string is "(" + a valid string with i pairs + ")" + a valid string with n - 1 - i pairs, so the answers for n can be built from the answers for smaller n.

## Pattern
Backtracking: add a bracket, recurse, then remove it. The counts of opening and closing brackets are enough to know which bracket is allowed next, so invalid strings are never built and nothing has to be checked at the end. The same buffer is reused for every string instead of copying it at each step.

## Complexity
O(4ⁿ / √n) time, O(n) space not counting the output.
