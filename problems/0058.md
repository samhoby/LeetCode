# 58. Length of Last Word

- **Difficulty:** Easy
- **Topics:** [String](../README.md#string)
- **Link:** https://leetcode.com/problems/length-of-last-word/

## Key idea
The last word is at the end, so read the string backwards. Skip the trailing spaces, then count characters until a space or the start of the string. Only the trailing spaces and the last word are ever read.

## Pattern
Backward scan with a single index: skip the trailing spaces, then count until a space or the start.

## Complexity
O(n) time, O(1) space.
