# 58. Length of Last Word

- **Difficulty:** Easy
- **Topics:** [String](../README.md#string)
- **Link:** https://leetcode.com/problems/length-of-last-word/

## Key idea
Start from the end. Skip the trailing spaces, then count characters until you hit a space or the start of the string. Only the trailing spaces and the last word are read.

## Pattern
Backward scan with a single index: skip the trailing spaces, then count until a space or the start.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun lengthOfLastWord(s: String): Int {
        var i = s.lastIndex
        while (s[i] == ' ') i--
        
        var length = 0
        while (i >= 0 && s[i] != ' ') {
            length++
            i--
        }
        
        return length
    }
}
```
