# 178. Rank Scores

- **Difficulty:** Medium
- **Topics:** [Database](../README.md#database)
- **Link:** https://leetcode.com/problems/rank-scores/

## Key idea
Rank the scores from highest to lowest, where equal scores share a rank and the next different score gets the very next rank, with no gaps. A window function does this over all the rows at once, without grouping them, so every score keeps its own row and gets its rank next to it.

Example with the scores 3.50, 3.65, 4.00, 3.85, 4.00 and 3.65: the two 4.00 are rank 1, 3.85 is rank 2, the two 3.65 are rank 3 and 3.50 is rank 4.

## Pattern
`dense_rank()` over the scores sorted from highest to lowest. `rank()` would leave gaps after a tie (1, 1, 3), and `row_number()` would give equal scores different ranks, so only `dense_rank()` fits.
## Complexity
O(n log n) time, O(n) space, where n is the number of rows in `Scores`.
