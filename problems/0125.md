# 125. Valid Palindrome

- **Difficulty:** Easy
- **Topics:** [Two Pointers](../README.md#two-pointers), [String](../README.md#string)
- **Link:** https://leetcode.com/problems/valid-palindrome/

## Key idea
A palindrome reads the same from both ends, so compare characters from the outside in, ignoring anything that isn't a letter or digit and ignoring case. The comparison is done on `s` itself: each end skips the characters that aren't letters or digits as it moves in, so no cleaned copy is made.

## Pattern
Two pointers moving inward from both ends. The skipping loops also check that the ends haven't met, so a string with no letters or digits doesn't run past the middle.

## Complexity
O(n) time, O(1) space.
