# 125. Valid Palindrome

- **Difficulty:** Easy
- **Topics:** [Two Pointers](../README.md#two-pointers), [String](../README.md#string)
- **Link:** https://leetcode.com/problems/valid-palindrome/

## Key idea
Remove everything that isn’t a letter or digit and lowercase the rest, so only the characters that matter are left. Then compare from both ends: one pointer at the start and one at the end, moving toward the middle. If any pair differs, it’s not a palindrome. If the pointers meet without a mismatch, it is.

## Pattern
Two pointers moving inward from both ends. Pre-cleaning the string with `filter` and `lowercase` keeps the comparison simple.

Alternative: skip the filter and move each pointer past non-alphanumeric characters as you go. That gets O(1) space, but it was slower in practice, even though it’s still O(n) time.

## Complexity
O(n) extra space. O(n) time.

## Code 1
```kotlin
class Solution {
    fun isPalindrome(s: String): Boolean {
        val alpha = s.filter { char -> char.isLetterOrDigit() }.lowercase()
        var left = 0
        var right = alpha.length-1
        
        while (left < right) {
            if (alpha[left] != alpha[right]) return false
            left++
            right--
        }
        
        return true
    }
}
```

## Code 2
```kotlin
class Solution {
    fun isPalindrome(s: String): Boolean {
        var left = 0
        var right = s.lastIndex
        
        while (left < right) {
            while (left < right && !s[left].isLetterOrDigit()) left++
            while (left < right && !s[right].isLetterOrDigit()) right--
            
            if (s[left].lowercaseChar() != s[right].lowercaseChar()) return false
            
            left++
            right--
        }
        
        return true
    }
}
```
