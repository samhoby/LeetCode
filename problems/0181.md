# 181. Employees Earning More Than Their Managers

- **Difficulty:** Easy
- **Topics:** [Database](../README.md#database)
- **Link:** https://leetcode.com/problems/employees-earning-more-than-their-managers/

## Key idea
Each employee's manager is another row of the same `Employee` table, found through `managerId`. Join the table with itself, matching each employee's `managerId` to the manager's `id`, so every row has the employee's salary next to the manager's. Then keep only the rows where the employee earns more. Employees with no manager have no match, so they drop out, which is right since there's no manager to earn more than.

Example: Joe earns 70000 and his manager Sam earns 60000, so Joe is in the result. Henry earns 80000 but his manager Max earns 90000, so he isn't. Sam and Max have no manager, so the answer is only Joe.

## Pattern
Self join with two aliases of the same table, one for the employee and one for the manager. It's an inner join, unlike the left join in [Combine Two Tables](0175.md), because the rows without a manager should be dropped. The column is renamed to `Employee`, as the problem asks.

## Complexity
O(n) time, O(n) space with a hash join, where n is the number of rows in `Employee`.
