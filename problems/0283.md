# 283. Move Zeroes

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Two Pointers](../README.md#two-pointers)
- **Link:** https://leetcode.com/problems/move-zeroes/

## Key idea
Move every non-zero number to the front, keeping their order. `i` is where the next non-zero should go, and `j` goes through every number. When `nums[j]` isn't 0, swap it into position `i` and move `i` forward. Everything before `i` is then non-zero, in the same order as before, and the 0s get pushed to the end by the swaps. `i != j` skips swapping a number with itself, which happens while there's no 0 yet.

Example with `[0, 1, 0, 3, 12]`: 1, 3 and 12 are swapped into positions 0, 1 and 2, giving `[1, 3, 12, 0, 0]`.

## Pattern
Two pointers in the same direction: a fast one (`j`) that reads and a slow one (`i`) that writes, all in place.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun moveZeroes(nums: IntArray): Unit {
        var i = 0

        for (j in nums.indices) {
            if (nums[j] != 0) {
                if (i != j) exchange(nums, i, j)
                i++
            }
        }
    }

    private fun exchange(nums: IntArray, i: Int, j: Int): Unit {
        val tmp = nums[i]
        nums[i] = nums[j]
        nums[j] = tmp 
    }
}
```
