# 283. Move Zeroes

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Two Pointers](../README.md#two-pointers)
- **Link:** https://leetcode.com/problems/move-zeroes/

## Key idea
Move every non-zero number to the front, keeping their order. One pointer reads the numbers one by one, and a second one marks where the next non-zero number should go. Each non-zero number is swapped into that position, which then moves forward. Everything before it is non-zero, in the original order, and the 0s get pushed toward the end.

Example with `[0, 1, 0, 3, 12]`: 1, 3 and 12 are swapped into positions 0, 1 and 2, giving `[1, 3, 12, 0, 0]`.

## Pattern
Two pointers in the same direction: a fast one (`j`) that reads and a slow one (`i`) that writes, all in place.

## Complexity
O(n) time, O(1) space.
