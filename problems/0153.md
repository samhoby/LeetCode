# 153. Find Minimum in Rotated Sorted Array

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/

## Key idea
A rotated sorted array is two sorted parts, and the minimum is where the second part starts. Compare `nums[mid]` with `nums[right]`. If `nums[mid]` is bigger, the drop is after `mid`, so `left = mid + 1`. If not, `mid..right` is sorted, so the minimum is at `mid` or before it, so `right = mid` (not `mid - 1`, since `mid` could be the minimum). When `left` and `right` meet, that's the minimum.

Example with `[4, 5, 6, 7, 0, 1, 2]`: `nums[mid]` is 7, bigger than 2, so `left` moves to the 0. Then `nums[mid]` is 1, not bigger than 2, so `right` moves to the 1. Then `nums[mid]` is 0, not bigger than 1, so `right` moves to the 0. They meet, so the answer is 0.

## Pattern
Binary search without a target: compare with the right end to know which half has the drop.

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun findMin(nums: IntArray): Int {
        var left = 0
        var right = nums.lastIndex

        while (left < right) {
            val mid = (left + right) / 2
            if (nums[mid] > nums[right]) left = mid + 1 else right = mid
        }

        return nums[left]
    }
}
```
