# 153. Find Minimum in Rotated Sorted Array

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/

## Key idea
A rotated sorted array is two sorted parts, and the minimum is where the second part starts. Compare the middle with the right end. If the middle is bigger, the drop is to the right of the middle, so the minimum is there. If not, everything from the middle to the right end is sorted, so the minimum is the middle itself or to its left. Keep halving until one element is left.

Example with `[4, 5, 6, 7, 0, 1, 2]`: the middle 7 is bigger than the right end 2, so the minimum is in `[0, 1, 2]`. There the middle 1 isn't bigger than 2, so it's in `[0, 1]`. The middle 0 isn't bigger than 1, so only 0 is left.

## Pattern
Binary search without a target: compare with the right end to know which half has the drop.

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun findMin(nums: IntArray): Int {
        var left = 0
        var right = nums.lastIndex

        while (left < right) {
            val mid = (left + right) / 2
            if (nums[mid] > nums[right]) left = mid + 1 else right = mid
        }

        return nums[left]
    }
}
```
