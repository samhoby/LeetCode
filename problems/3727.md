# 3727. Maximum Alternating Sum of Squares

- **Difficulty:** Medium
- **Topics:** [Senior](../README.md#senior), [Array](../README.md#array), [Greedy](../README.md#greedy), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/maximum-alternating-sum-of-squares/

## Key idea
The elements can be rearranged freely, and a number's sign doesn't matter once it's squared, since (-3)² = 3². So only the squares matter. To maximize the alternating sum, put the smallest squares in the subtracted positions and the largest in the added ones: sort the squares, subtract the smallest half (n/2, rounded down) and add the rest. The squares can overflow a 32-bit integer, so they're computed with 64 bits.

## Pattern
Greedy + sorting: put the smallest values in the minus slots and the largest in the plus slots.

## Complexity
O(n log n) time, O(n) space.

## Code
```kotlin
class Solution {
    fun maxAlternatingSum(nums: IntArray): Long {
        val squaredNums = LongArray(nums.size) { nums[it].toLong() * nums[it] }
        squaredNums.sort()

        var i = 0
        val n = squaredNums.size
        var res = 0L

        while (i < n/2) {
            res -= squaredNums[i]
            i++
        }

        while (i <= n-1) {
            res += squaredNums[i]
            i++
        }
        
        return res
    }
}
```
