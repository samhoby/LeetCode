# 3727. Maximum Alternating Sum of Squares

- **Difficulty:** Medium
- **Topics:** [Senior](../README.md#senior), [Array](../README.md#array), [Greedy](../README.md#greedy), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/maximum-alternating-sum-of-squares/

## Key idea
The elements can be rearranged freely, so only the squares matter, not where the numbers started. Square everything (as `Long`, since `nums[i] * nums[i]` can overflow `Int`), sort, subtract the `n/2` smallest squares and add the rest. Squaring also makes negatives irrelevant, since `(-3)² = 3²`.

## Pattern
Greedy + sorting: put the smallest values in the minus slots and the largest in the plus slots.

## Complexity
O(n log n) time, O(n) space.

## Code
```kotlin
class Solution {
    fun maxAlternatingSum(nums: IntArray): Long {
        val squaredNums = LongArray(nums.size) { nums[it].toLong() * nums[it] }
        squaredNums.sort()

        var i = 0
        val n = squaredNums.size
        var res = 0L

        while (i < n/2) {
            res -= squaredNums[i]
            i++
        }

        while (i <= n-1) {
            res += squaredNums[i]
            i++
        }
        
        return res
    }
}
```
