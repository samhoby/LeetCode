# 3727. Maximum Alternating Sum of Squares

- **Difficulty:** Medium
- **Topics:** [Senior](../README.md#senior), [Array](../README.md#array), [Greedy](../README.md#greedy), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/maximum-alternating-sum-of-squares/

## Key idea
The elements can be rearranged freely, and a number's sign doesn't matter once it's squared, since (-3)² = 3². So only the squares matter. To maximize the alternating sum, put the smallest squares in the subtracted positions and the largest in the added ones: sort the squares, subtract the smallest half (n/2, rounded down) and add the rest. The squares can be too big for 32 bits, so with fixed-size integers they have to be computed with 64 bits.

## Pattern
Greedy + sorting: put the smallest values in the minus slots and the largest in the plus slots.

## Complexity
O(n log n) time, O(n) space.
