# 28. Find the Index of the First Occurrence in a String

- **Difficulty:** Easy
- **Topics:** [Two Pointers](../README.md#two-pointers), [String](../README.md#string), [String Matching](../README.md#string-matching), [Z Algorithm](../README.md#z-algorithm), [Knuth-Morris-Pratt Algorithm](../README.md#knuth-morris-pratt-algorithm), [Boyer-Moore String-Search Algorithm](../README.md#boyer-moore-string-search-algorithm)
- **Link:** https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/

## Key idea
Try every position of `haystack` where `needle` could start, from the first one to the last one that still leaves room for all of `needle`. At each position, compare the characters one by one and stop at the first mismatch. The first position where all of `needle` matches is the answer. If none does, or `needle` is longer than `haystack`, the answer is -1.

Example with `haystack = "sadbutsad"` and `needle = "sad"`: it already matches at position 0, so the answer is 0. With `haystack = "leetcode"` and `needle = "leeto"`, every position fails, so the answer is -1.

This is the brute force check. The Z Algorithm, Knuth-Morris-Pratt and Boyer-Moore topics are faster string matching algorithms that avoid starting over from scratch at every position. Those algorithms reach O(n + m), but they're only worth it if this search is actually a bottleneck. Otherwise the simple version is the better choice, because readable code matters as much as efficient code.

## Pattern
Brute force string matching with two pointers: one for where `needle` starts in `haystack`, and one for how many characters already matched.

## Complexity
O(n · m) time, O(1) space, where n is the length of `haystack` and m is the length of `needle`.
