# 137. Single Number II

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Bit Manipulation](../README.md#bit-manipulation)
- **Link:** https://leetcode.com/problems/single-number-ii/

## Key idea
For each bit, count how many numbers have a 1 there. The numbers that appear 3 times add 0 or 3 to that count, so `bitCount % 3` is the single number's bit. Example with `[5, 5, 5, 3]`:

|              | bit 2     | bit 1     | bit 0     |
| ------------ | --------- | --------- | --------- |
| 5            | 1         | 0         | 1         |
| 5            | 1         | 0         | 1         |
| 5            | 1         | 0         | 1         |
| 3            | 0         | 1         | 1         |
| bitCount % 3 | 3 % 3 = 0 | 1 % 3 = 1 | 4 % 3 = 1 |

The `bitCount % 3` row read left to right is `011`, which is 3.

The code counts one bit at a time and sets that bit in `res` if `bitCount % 3 != 0`.

## Pattern
Count the 1s per bit, modulo 3. Works for any "every number appears k times except one" problem, just change 3 to k.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun singleNumber(nums: IntArray): Int {
        var res = 0

        for (bit in 0 until 32) {
            var bitCount = 0

            for (num in nums) {
                // bitCount += (num >> bit) & 1
                bitCount += (num shr bit) and 1
            }

            if (bitCount % 3 != 0) {
                // res |= (1 << bit)
                res = res or (1 shl bit) 
            }
        }

        return res
    }
}
```
