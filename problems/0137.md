# 137. Single Number II

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Bit Manipulation](../README.md#bit-manipulation)
- **Link:** https://leetcode.com/problems/single-number-ii/

## Key idea
The goal is to find the number that appears once when every other number appears three times. Each bit position can be looked at on its own: every time a number with a 1 in that bit shows up, the bit moves one step through a cycle of three states. It starts as not seen, then becomes seen once, then seen twice, and the third time it goes back to not seen. Two values hold these states for all bits at once, one with the bits seen once and one with the bits seen twice.

When a number comes in, a bit only enters seen once if it isn't already in seen twice, because the third time must clear it, not start it again. Then a bit only enters seen twice if it didn't just land in seen once. After all the numbers, each number that appears three times has taken its bits around the full cycle back to not seen, so the seen once value holds exactly the bits of the single number.

Example with `[5, 5, 5, 3]`, with the values after each number:

| number | seen once | seen twice |
| ------ | --------- | ---------- |
| 5      | 101       | 000        |
| 5      | 000       | 101        |
| 5      | 000       | 000        |
| 3      | 011       | 000        |

At the end seen once is `011`, which is 3.

## Pattern
A counter mod 3 for every bit at once, kept in two bitmasks. The second line uses the value the first line just computed, not the old one. That order is what stops a bit from being in both masks at the same time.

## Complexity
O(n) time, O(1) space.
