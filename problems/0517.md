# 517. Super Washing Machines

- **Difficulty:** Hard
- **Topics:** [Principal](../README.md#principal), [Array](../README.md#array), [Greedy](../README.md#greedy)
- **Link:** https://leetcode.com/problems/super-washing-machines/

## Key idea
If the dresses can't be split evenly between the n machines, the answer is -1. Otherwise each machine has to end with the total divided by n, so each one has a surplus or a deficit. The answer is the biggest of two limits:

- Between any two neighbouring machines, all the surplus on the left has to cross to the right, or the other way around. That's the running sum of surpluses up to that point. Only one dress crosses that border per move, so it takes at least that many moves.
- A machine with a surplus can only give away one dress per move, so it needs at least as many moves as its surplus. A machine with a deficit doesn't limit it the same way, because it can receive from both sides in the same move.

Moving dresses greedily toward where they're missing reaches that biggest limit, so it's the answer.

Example with `machines = [1,0,5]`: the total is 6, so each machine needs 2, and the surpluses are -1, -2 and 3. The running sums are -1, -3 and 0, so 3 dresses have to cross between the second and third machine. The third machine also has a surplus of 3. The answer is 3.

## Pattern
Greedy lower bound: the answer is the worst bottleneck, either the flow across one border or the surplus of one machine.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun findMinMoves(machines: IntArray): Int {
        var totalDreses = 0
        for (m in machines) totalDreses += m

        val n = machines.size
        if (totalDreses % n != 0) return -1

        val dressesPerMachine = totalDreses / n
        var moves = 0
        var balance = 0

        for (m in machines) {
            val diff = m - dressesPerMachine
            balance += diff
            moves = maxOf(moves, abs(balance), diff)
        }

        return moves
    }
}
```
