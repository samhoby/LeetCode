# 268. Missing Number

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Math](../README.md#math), [Binary Search](../README.md#binary-search), [Bit Manipulation](../README.md#bit-manipulation), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/missing-number/

## Key idea
The numbers should be 0 to n, where n is the length of `nums`, and exactly one is missing. XOR all the numbers from 0 to n together with all the numbers in `nums`. Every number that's present appears twice and cancels, like in [Single Number I](0136.md), so only the missing one is left.

Example with `[3, 0, 1]`: 3 ⊕ 0 ⊕ 3 ⊕ 1 ⊕ 0 ⊕ 2 ⊕ 1 = 2, since 0, 1 and 3 appear twice and cancel.

This solution doesn't use a hash table, sorting, binary search or math. Those topics are for other approaches: put every number in a set and check 0 to n (O(n) space), sort and binary search for the first position whose number isn't equal to it (O(n log n) time), or subtract the sum of `nums` from the sum of 0 to n, n(n + 1) / 2, which can overflow for a very large n.

## Pattern
Cancel pairs with XOR (Bit Manipulation). The result starts at n, because the indices only go from 0 to n - 1, so n has to be added separately. Unlike the sum formula, XOR never overflows.

## Complexity
O(n) time, O(1) space.
