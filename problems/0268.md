# 268. Missing Number

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Math](../README.md#math), [Binary Search](../README.md#binary-search), [Bit Manipulation](../README.md#bit-manipulation), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/missing-number/

## Key idea
The numbers should be `[0, n]`, where n is `nums.size`, and exactly one is missing.

Code 1: the full sum of 0 to n is `n * (n + 1) / 2`. Subtract the actual `sum` of `nums` and what's left is the missing number. For a very large n, `n * (n + 1)` can overflow `Int`.

Code 2: XOR every index and every number together, plus n (that's why `res` starts at `nums.size`, since n is never an index). Each number that's present cancels with the same index, like in [Single Number I](0136.md), so only the missing number is left. XOR never overflows.

Example with `[3, 0, 1]`:

- Code 1: the full sum is 0 + 1 + 2 + 3 = 6, the actual sum is 3 + 0 + 1 = 4, so the missing number is 6 - 4 = 2.
- Code 2: 3 ⊕ 0 ⊕ 3 ⊕ 1 ⊕ 0 ⊕ 2 ⊕ 1 = 2, since 0, 1 and 3 appear twice and cancel.

Neither code uses a hash table, sorting or binary search. Those topics are for other approaches: put every number in a set and check 0 to n (O(n) space), or sort and binary search for the first index where `nums[i] != i` (O(n log n) time).

## Pattern
Compare what you have with what you should have. Code 1 uses the sum formula (Math), Code 2 uses XOR to cancel pairs (Bit Manipulation).

## Complexity
Both: O(n) time, O(1) space.

## Code 1
```kotlin
class Solution {
    fun missingNumber(nums: IntArray): Int {
        var sum = 0
        for (num in nums) sum += num 
        return ((nums.size*(nums.size+1))/2) - sum
    }
}
```

## Code 2 (No overflow)
```kotlin
class Solution {
    fun missingNumber(nums: IntArray): Int {
        var res = nums.size
        for (i in nums.indices) res = res xor i xor nums[i]
        return res
    }
}
```
