# 9. Palindrome Number

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math)
- **Link:** https://leetcode.com/problems/palindrome-number/

## Key idea
Reverse only half of the number using `% 10` (take the last digit) and `/ 10` (remove it), moving digits from `num` to `reversed` until `reversed` catches up with `num`. Then compare the two halves. For an odd number of digits, `reversed` has one extra middle digit, so drop it with `reversed / 10`. Negatives and numbers ending in 0 (except 0) are never palindromes, so return `false` early.

## Pattern
Digit manipulation with `% 10` and `/ 10`, no strings. Reversing only half avoids overflow.

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun isPalindrome(x: Int): Boolean {
        // negative or ends with 0 (except 0)
        if (x < 0 || (x % 10 == 0 && x != 0)) return false
        
        var num = x
        var reversed = 0
        
        // reverse only half of the number
        while (num > reversed) {
	        // write last digit of num to reversed
            reversed = reversed * 10 + num % 10
            // remove last digit of num
            num /= 10 
        }
        // even size (1221) || odd size (121)
        return num == reversed || num == reversed / 10 
    }
}
```
