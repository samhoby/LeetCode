# 9. Palindrome Number

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math)
- **Link:** https://leetcode.com/problems/palindrome-number/

## Key idea
Reverse only the second half of the number and compare it with the first half. Take the last digit off the number (mod 10) and append it to the reversed half (times 10, plus the digit), until the reversed half is at least as big as what's left. For an odd number of digits, the middle digit ends up in the reversed half, so drop it before comparing. Negatives and numbers ending in 0 (except 0) can never be palindromes.

## Pattern
Digit manipulation with `% 10` and `/ 10`, no strings. Reversing only half avoids overflow.

## Complexity
O(log n) time, O(1) space.
