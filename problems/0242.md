# 242. Valid Anagram

- **Difficulty:** Easy
- **Topics:** [Hash Table](../README.md#hash-table), [String](../README.md#string), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/valid-anagram/

## Key idea
Two strings are anagrams if every character appears the same number of times in both. Count the characters of `s`, then subtract the characters of `t`. If a count ever goes below 0, `t` has that character more times than `s`. Since the lengths are equal, if nothing goes below 0, every count ends at 0.

This solution doesn't sort. The Sorting topic is for the other approach: sort both strings and compare them. It's simpler to write, but O(n log n) instead of O(n).

## Pattern
Frequency count with a hash map: add for one string, subtract for the other. Counting by code point, not by 16-bit unit, makes it work for any Unicode character, like 😀, which takes two 16-bit units.

## Complexity
O(n) time, O(k) space, where k is the number of different characters.
