# 167. Two Sum II - Input Array Is Sorted

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Two Pointers](../README.md#two-pointers), [Binary Search](../README.md#binary-search)
- **Link:** https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/

## Key idea
The array `numbers` is sorted, so start with the smallest and the largest number. If their sum is too big, the largest can't be part of the answer, since even with the smallest it's already too much, so drop it. If the sum is too small, the smallest can't be part of it either, so drop that one. Each step rules out one number, until the sum is exactly `target`. The answer uses 1-based positions, as the problem asks.

Example with `numbers = [2,7,11,15]` and `target = 9`: 2 + 15 = 17 is too big, so 15 goes. 2 + 11 = 13 is still too big, so 11 goes. 2 + 7 = 9, so the answer is `[1,2]`.

The Binary Search topic is for another approach: for each number, binary search the rest for `target` minus it, which is O(n log n).

## Pattern
Two pointers from both ends. Unlike [Two Sum](0001.md), the sorted order replaces the hash map, so no extra space is needed.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun twoSum(numbers: IntArray, target: Int): IntArray {
        var left = 0
        var right = numbers.lastIndex

        while (left < right) {
            val sum = numbers[left] + numbers[right]
            when {
                sum > target -> right--
                sum < target -> left++
                else -> return intArrayOf(left + 1, right + 1)
            }
        }

        return intArrayOf(-1, -1)
    }
}
```
