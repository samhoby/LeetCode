# 176. Second Highest Salary

- **Difficulty:** Medium
- **Topics:** [Database](../README.md#database)
- **Link:** https://leetcode.com/problems/second-highest-salary/

## Key idea
The goal is the second highest distinct salary, or null if there isn't one. Sort the distinct salaries from highest to lowest, skip the first and take the next one. Equal salaries count once, so a tie for the highest doesn't make it the second highest too. If there are fewer than two distinct salaries, nothing is left after skipping the first, and the answer has to be null instead of an empty result.

Example: with salaries 100, 200 and 300, the sorted list is 300, 200, 100, and skipping 300 gives 200. With only 100, nothing is left after skipping it, so the answer is null.

## Pattern
`distinct` + `order by ... desc` + `offset 1 limit 1`. The outer `select` around the query is what turns "no row" into a row with null. Without it, a table with one salary would give an empty result.

## Complexity
O(n log n) time, O(n) space, where n is the number of rows in `Employee`.
