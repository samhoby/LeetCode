# 180. Consecutive Numbers

- **Difficulty:** Medium
- **Topics:** [Database](../README.md#database)
- **Link:** https://leetcode.com/problems/consecutive-numbers/

## Key idea
A number appears at least three times in a row if some row has the same number as the row right before it and the row right after it, in `id` order. So put each row's number next to the previous and the next one, and keep the rows where all three are equal. A run longer than three matches on several rows, so each number is listed only once.

Example with the numbers 1, 1, 1, 2, 1, 2, 2: only the second row has a 1 before it and a 1 after it, so the answer is 1. The 2s are never three in a row.

## Pattern
`lag` and `lead` over the rows sorted by `id` to read the previous and next row without a self join. The comparison has to be in an outer query, because window functions can't be used in `where`. `distinct` removes the repeats from runs of four or more. The first and last rows have null as their missing neighbour, and a comparison with null is never true, so they're never matched by mistake.

## Complexity
O(n log n) time, O(n) space, where n is the number of rows in `Logs`.
