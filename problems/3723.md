# 3723. Maximize Sum of Squares of Digits

- **Difficulty:** Medium
- **Topics:** [Staff](../README.md#staff), [Math](../README.md#math), [Greedy](../README.md#greedy)
- **Link:** https://leetcode.com/problems/maximize-sum-of-squares-of-digits/

## Key idea
To make the sum of squares as big as possible, put the digit sum into the fewest, biggest digits. Moving 1 from a smaller digit to a bigger one always increases the squares, e.g. 5² + 5² = 50 but 9² + 1² = 82. So use as many 9s as possible, then one digit with whatever is left, then 0s. Putting the 9s first also makes it the largest number among the ties.

If `sum` is more than 9 times `num`, even all 9s can't reach it, so there's no answer.

Example with `num = 3` and `sum = 20`: two 9s make 18, and the 2 left over becomes the third digit, so the answer is "992".

## Pattern
Greedy: take the biggest digit you can at every position. `'0' + remainder` turns the `Int` into its digit `Char`.

## Complexity
O(num) time, O(num) space.

## Code
```kotlin
class Solution {
    fun maxSumOfSquares(num: Int, sum: Int): String {
        if (sum > num * 9) return ""

        val nines = sum / 9
        val remainder = sum % 9

        val arr = CharArray(num) { i ->
            when {
                i < nines -> '9'
                i == nines && remainder > 0 -> '0' + remainder
                else -> '0'
            }
        }

        return String(arr)
    }
}
```
