# 1502. Can Make Arithmetic Progression From Sequence

- **Difficulty:** Easy
- **Topics:** [Mid Level](../README.md#mid-level), [Array](../README.md#array), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/can-make-arithmetic-progression-from-sequence/

## Key idea
Code 1: in a sorted arithmetic progression, every pair of neighbours has the same difference. So sort and check that every difference matches the first one.

Code 2: no sorting. If the numbers form a progression, the smallest and largest are its two ends, so the common difference has to be (max - min) / (n - 1). If that doesn't divide evenly, it's not a progression. Then every number must land exactly on a step from the smallest one, and no two numbers can land on the same step. There are n numbers and n steps, so if none repeat, every step is filled. If all numbers are equal, it's a progression with difference 0.

Example with `[3, 5, 1]`:

- Code 1: sorted it's `[1, 3, 5]`, and both differences are 2, so it's `true`.
- Code 2: the smallest is 1 and the largest is 5, so the difference is 4 / 2 = 2. 1 is on step 0, 3 on step 1 and 5 on step 2, all different, so it's `true`.

## Pattern
Code 1 is the simple one: sort and compare neighbours. Code 2 avoids sorting with math: get `d` from `min` and `max`, then use a set to check that each number lands on its own step. It's faster, but uses extra space.

## Complexity
Code 1: O(n log n) time, O(1) space.

Code 2: O(n) time, O(n) space.

## Code 1
```kotlin
class Solution {
    fun canMakeArithmeticProgression(arr: IntArray): Boolean {
        arr.sort()
        val d = arr[1] - arr[0] // common difference

        for (i in 2..arr.lastIndex) {
            if (arr[i] - arr[i-1] != d) return false
        }

        return true
    }
}
```

## Code 2
```kotlin
class Solution {
    fun canMakeArithmeticProgression(arr: IntArray): Boolean {
        val n = arr.size
        val min = arr.min()
        val max = arr.max()

        if (min == max) return true                  
        if ((max - min) % (n - 1) != 0) return false 

        val d = (max - min) / (n - 1) // common difference
        val seen = HashSet<Int>()

        for (x in arr) {
            if ((x - min) % d != 0) return false     
            if (!seen.add((x - min) / d)) return false 
        }

        return true
    }
}
```
