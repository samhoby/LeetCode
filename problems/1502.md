# 1502. Can Make Arithmetic Progression From Sequence

- **Difficulty:** Easy
- **Topics:** [Mid Level](../README.md#mid-level), [Array](../README.md#array), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/can-make-arithmetic-progression-from-sequence/

## Key idea
Code 1: sort the array, then every pair of neighbours must have the same difference `d`, taken from the first two numbers.

Code 2: no sorting. If the numbers form a progression, `min` and `max` are its two ends, so the common difference has to be `d = (max - min) / (n - 1)`. If that doesn't divide evenly, it's not a progression. Then every number must sit exactly on one step of the progression: `(x - min) % d == 0`, and its position `(x - min) / d` can't be taken already, which `seen` checks. There are n numbers and n positions (0 to n - 1), so if none repeat, every position is filled. If `min == max`, all numbers are equal, which is a progression with `d = 0`. It's checked first to avoid dividing by 0.

Example with `[3, 5, 1]`:

- Code 1: sorted it's `[1, 3, 5]`, `d` is 2, and 5 - 3 is also 2, so it's `true`.
- Code 2: `min` is 1, `max` is 5, so `d` is 4 / 2 = 2. 1 is at position 0, 3 at 1 and 5 at 2, all different, so it's `true`.

## Pattern
Code 1 is the simple one: sort and compare neighbours. Code 2 avoids sorting with math: get `d` from `min` and `max`, then use a set to check that each number lands on its own step. It's faster, but uses extra space.

## Complexity
Code 1: O(n log n) time, O(1) space.

Code 2: O(n) time, O(n) space.

## Code 1
```kotlin
class Solution {
    fun canMakeArithmeticProgression(arr: IntArray): Boolean {
        arr.sort()
        val d = arr[1] - arr[0] // common difference

        for (i in 2..arr.lastIndex) {
            if (arr[i] - arr[i-1] != d) return false
        }

        return true
    }
}
```

## Code 2
```kotlin
class Solution {
    fun canMakeArithmeticProgression(arr: IntArray): Boolean {
        val n = arr.size
        val min = arr.min()
        val max = arr.max()

        if (min == max) return true                  
        if ((max - min) % (n - 1) != 0) return false 

        val d = (max - min) / (n - 1) // common difference
        val seen = HashSet<Int>()

        for (x in arr) {
            if ((x - min) % d != 0) return false     
            if (!seen.add((x - min) / d)) return false 
        }

        return true
    }
}
```
