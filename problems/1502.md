# 1502. Can Make Arithmetic Progression From Sequence

- **Difficulty:** Easy
- **Topics:** [Mid Level](../README.md#mid-level), [Array](../README.md#array), [Sorting](../README.md#sorting)
- **Link:** https://leetcode.com/problems/can-make-arithmetic-progression-from-sequence/

## Key idea
In a sorted arithmetic progression, every pair of neighbours has the same difference. So sort `arr` and check that every difference matches the first one.

Example with `[3, 5, 1]`: sorted it's `[1, 3, 5]`, and both differences are 2, so it's `true`.

## Pattern
Sort, then compare neighbours. The first difference is the reference, so the check starts at the third number. An O(n) version exists without sorting, using the smallest and largest numbers and a set, but it has more edge cases, and with at most 1000 numbers the sort is never the bottleneck.

## Complexity
O(n log n) time, O(1) space.
