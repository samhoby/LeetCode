# 219. Contains Duplicate II

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Sliding Window](../README.md#sliding-window)
- **Link:** https://leetcode.com/problems/contains-duplicate-ii/

## Key idea
Two equal numbers at most `k` positions apart means that, when the second one comes, the first is among the last `k` numbers. So keep a hash set with only the last `k` numbers. If the current number is already in it, the earlier copy is close enough. After each step, the number that's now more than `k` positions back leaves the set.

## Pattern
Sliding window + hash set: the set only ever holds the window, so any match is automatically within distance `k`. Same “have I seen this before?” idea as Contains Duplicate, with a size limit. 

## Complexity
O(n) time, O(k) space.
