# 219. Contains Duplicate II

- **Difficulty:** Easy
- **Topics:** [Array](../README.md#array), [Hash Table](../README.md#hash-table), [Sliding Window](../README.md#sliding-window)
- **Link:** https://leetcode.com/problems/contains-duplicate-ii/

## Key idea
Keep a set holding only the last `k` numbers (a sliding window). If the current number is already in the set, a duplicate exists within distance `k`, so return `true`. After adding, if the set grows past `k`, remove `nums[i - k]`, the number that just left the window.

## Pattern
Sliding window + hash set: the set only ever holds the window, so any match is automatically within distance `k`. Same “have I seen this before?” idea as Contains Duplicate, with a size limit. 

## Complexity
O(n) time, O(k) space.

## Code
```kotlin
class Solution {
    fun containsNearbyDuplicate(nums: IntArray, k: Int): Boolean {
        val seen = HashSet<Int>()
        
        for (i in nums.indices) {
            when {
                !seen.add(nums[i]) -> return true
                seen.size > k -> seen.remove(nums[i-k])
            }
        }
        
        return false
    }
}
```
