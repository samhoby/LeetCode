# 69. Sqrt(x)

- **Difficulty:** Easy
- **Topics:** [Math](../README.md#math), [Binary Search](../README.md#binary-search), [Newton's Method](../README.md#newtons-method)
- **Link:** https://leetcode.com/problems/sqrtx/

## Key idea
The answer is the largest number whose square is at most `x`. As the number grows, "square <= x" goes from true to false only once, so binary search can find where it flips. The square can overflow a 32-bit integer, so it's computed with 64 bits.

## Pattern
Binary search on the answer: search the range of possible results instead of an array. 

## Complexity
O(log n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun mySqrt(x: Int): Int {
        var left = 0
        var right = x
        
        while (left <= right) {
            val mid = left + (right - left) / 2
            if (mid.toLong() * mid <= x) left = mid + 1 else right = mid - 1
        }
        
        return right
    }
}
```
