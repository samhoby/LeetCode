# 392. Is Subsequence

- **Difficulty:** Easy
- **Topics:** [Junior](../README.md#junior), [Two Pointers](../README.md#two-pointers), [String](../README.md#string), [Dynamic Programming](../README.md#dynamic-programming)
- **Link:** https://leetcode.com/problems/is-subsequence/

## Key idea
Go through `t` once and look for the characters of `s` in order. `i` is the next character of `s` still to find, and every time the current character `c` is `s[i]`, move `i` forward. If `i` reaches `s.length`, every character of `s` was found in order. The `i < s.length` check stops the code from reading past the end of `s` once it's fully matched.

Example with `s = "abc"` and `t = "ahbgdc"`: a, b and c are found in that order, so `i` ends at 3 and the answer is `true`.

This solution is greedy and doesn't use dynamic programming. That topic is for another approach, a table with the next position of each character in `t`.

## Pattern
Two pointers: the `for` loop moves over `t` every time, and `i` over `s` only when there's a match.

## Complexity
O(n) time, O(1) space, where n is the length of `t`.

## Code
```kotlin
class Solution {
    fun isSubsequence(s: String, t: String): Boolean {
        var i = 0
        
        for (c in t) {
            if (i < s.length && s[i] == c) i++
        }

        return i == s.length
    }
}
```

## Follow-up
Suppose there are lots of incoming `s`, say `s_1, s_2, ..., s_k` where `k >= 10^9`, and you want to check one by one to see if `t` has its subsequence. In this scenario, how would you change your code?

```kotlin
class Solution {
    fun isSubsequence(s: List<String>, t: String): Boolean {
        val positions = HashMap<Char, MutableList<Int>>()
        for (i in t.indices) positions.getOrPut(t[i]) { mutableListOf() }.add(i)

        for (str in s) {
            var prev = -1

            for (c in str) {
                val indices = positions[c] ?: return false

                var left = 0
                var right = indices.size
                
                while (left < right) {
                    val mid = (left + right) / 2
                    if (indices[mid] > prev) right = mid else left = mid + 1
                }

                if (left == indices.size) return false
                prev = indices[left]
            }
        }

        return true
    }
}
```

Instead of scanning `t` for every `s`, `t` is processed once into `positions`, a map from each character to the sorted indices where it appears. For each `s`, `prev` is the index in `t` of the last matched character. To match the next character, binary search its list in `positions` for the first index greater than `prev`. If there is none, `s` is not a subsequence. Otherwise `prev` moves to that index.

O(m log n) time per `s`, O(n) space, where n is the length of `t` and m is the length of `s`.
