# 260. Single Number III

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Bit Manipulation](../README.md#bit-manipulation)
- **Link:** https://leetcode.com/problems/single-number-iii/

## Key idea
XOR every number into `mask`. The pairs cancel, so `mask` ends up as `a xor b`, the two single numbers XORed together. Since `a` and `b` are different, `mask` has at least one bit set, and on that bit `a` and `b` are different. `takeLowestOneBit()` picks one of those bits (`lowestBit`).

Then split the numbers by that bit and XOR only the ones that have it into `first`. Each pair lands in the same group and cancels, while `a` and `b` land in different groups, so `first` ends up as one of them. The other one is `mask xor first`.

Example with `[1, 2, 1, 3, 2, 5]`: `mask` is 3 xor 5 = 6 (`110`), so `lowestBit` is 2 (`010`). The numbers with that bit are 2, 3, 2, so `first` is 3, and the other one is 6 xor 3 = 5.

## Pattern
XOR to cancel the pairs, like [Single Number I](0136.md), then use a bit where the two answers differ to split the array into two groups with one single number each. `takeLowestOneBit()` is the same as `mask and -mask`.

## Complexity
O(n) time, O(1) space.

## Code
```kotlin
class Solution {
    fun singleNumber(nums: IntArray): IntArray {
        var mask = 0
        // mask ^= num
        for (num in nums) mask = mask xor num   

        val lowestBit = mask.takeLowestOneBit() 
        var first = 0

        for (num in nums) {
            // XOR only the group that has lowestBit, pairs cancel, one single is left
            if ((num and lowestBit) != 0) first = first xor num
        }

        return intArrayOf(first, mask xor first)
    }
}
```
