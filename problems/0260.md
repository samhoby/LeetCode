# 260. Single Number III

- **Difficulty:** Medium
- **Topics:** [Array](../README.md#array), [Bit Manipulation](../README.md#bit-manipulation)
- **Link:** https://leetcode.com/problems/single-number-iii/

## Key idea
XOR all the numbers: the pairs cancel, so the result is the two single numbers XORed together. They're different, so that result has at least one bit set, and on that bit the two numbers differ. Use one such bit (the lowest) to split all the numbers into two groups. Each pair lands in the same group and cancels, while the two single numbers land in different groups. XORing one group gives one of them, and XORing it with the first result gives the other.

Example with `[1, 2, 1, 3, 2, 5]`: everything XORed is 3 xor 5 = 6 (`110`), and its lowest set bit is 2 (`010`). The numbers with that bit are 2, 3, 2, which XOR to 3. The other number is 6 xor 3 = 5.

## Pattern
XOR to cancel the pairs, like [Single Number I](0136.md), then use a bit where the two answers differ to split the array into two groups with one single number each. The lowest set bit is the XOR result ANDed with its negative, which keeps only that bit.

## Complexity
O(n) time, O(1) space.
