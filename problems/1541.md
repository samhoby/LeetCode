# 1541. Minimum Insertions to Balance a Parentheses String

- **Difficulty:** Medium
- **Level:** Staff
- **Topics:** [String](../README.md#string), [Stack](../README.md#stack), [Greedy](../README.md#greedy), [Bracket Sequences](../README.md#bracket-sequences)
- **Link:** https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/

## Key idea
A `(` is closed by `))`. Scan left to right and push every `(`. Each `)` checks two things: First, is the next char also `)`? If not, the second `)` is missing, so `count++`. Then, is there a `(` to close? If the stack is empty, the `(` is missing, so `count++`, otherwise `pop`. At the end, each leftover `(` still needs its `))`, so add `stack.size * 2`.

## Pattern
Bracket matching with a stack, where the stack only ever holds one kind of element, so a counter could replace it (O(1) space). 
Each `)` handles two separate checks (pair, and something to close). 

## Complexity
O(n) time, O(n) space.

## Code
```kotlin
class Solution {
    fun minInsertions(s: String): Int {
        val stack = Stack<Char>()
        var count = 0
        var i = 0
        
        while (i < s.length) {
            if (s[i] == '(') {
                stack.push(s[i])
                i++
                continue
            }
            
            if (i + 1 < s.length && s[i + 1] == ')') {
                i += 2
            } else {
                i += 1
                count++
            }
            
            if (stack.isEmpty()) count++ else stack.pop()  
        }
            
        return count + stack.size * 2
    }
}
```
