# 1541. Minimum Insertions to Balance a Parentheses String

- **Difficulty:** Medium
- **Topics:** [Staff](../README.md#staff), [String](../README.md#string), [Stack](../README.md#stack), [Greedy](../README.md#greedy), [Bracket Sequences](../README.md#bracket-sequences)
- **Link:** https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/

## Key idea
Each `(` needs `))`, two closing brackets in a row. Go through the string, keeping track of the `(` still open. Each `)` is the start of a `))`, so check two things. If the next character isn't also `)`, the second one is missing and has to be inserted. Then, if no `(` is open, one has to be inserted, otherwise the `))` closes the most recent one. At the end, each `(` still open needs two insertions for its `))`.

## Pattern
Bracket matching with a stack, where the stack only ever holds one kind of element, so a counter could replace it (O(1) space). 
Each `)` handles two separate checks (pair, and something to close). 

## Complexity
O(n) time, O(n) space.
