# 1541. Minimum Insertions to Balance a Parentheses String

- **Difficulty:** Medium
- **Level:** Staff
- **Topics:** [String](../README.md#string), [Stack](../README.md#stack), [Greedy](../README.md#greedy), [Bracket Sequences](../README.md#bracket-sequences)
- **Link:** https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/

## Key idea
Only `(` ever needs to be remembered, so what matters is how many are still unclosed. 
Scan left to right. A `(` is pushed. 
A `)` asks two independent questions: is it followed by another `)` (a pair)? If not, one `)` is missing, so `count++`. Then does it have a `(` to close? If the stack is empty, a `(` is missing, so `count++`, otherwise pop. At the end, each leftover `(` needs two `)`, so add `size * 2`.

## Pattern
Bracket matching with a stack, where the stack only ever holds one kind of element, so a counter replaces it (Code 2). 
Each `)` handles two separate checks (pair, and something to close). 

## Complexity
O(n) time, O(n) space for the stack, O(1) for the counter.

## Code 1
```kotlin
class Solution {
    fun minInsertions(s: String): Int {
        val stack = Stack<Char>()
        var count = 0
        var i = 0
        
        while (i < s.length) {
            if (s[i] == '(') {
                stack.push(s[i])
                i++
                continue
            }
            
            if (i + 1 < s.length && s[i + 1] == ')') {
                i += 2
            } else {
                i += 1
                count++
            }
            
            if (stack.isEmpty()) count++ else stack.pop()  
        }
            
        return count + stack.size * 2
    }
}
```

## Code 2 (Better)
```kotlin
class Solution {
    fun minInsertions(s: String): Int {
        var op = 0
        var count = 0
        var i = 0
        
        while (i < s.length) {
            if (s[i] == '(') {
                op++
                i++
                continue
            }
            
            if (i + 1 < s.length && s[i + 1] == ')') {
                i += 2
            } else {
                i += 1
                count++
            }
            
            if (op == 0) count++ else op--  
        }
            
        return count + op * 2
    }
}
```
